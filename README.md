# Apex Commercial Refrigeration — Website Template

## Overview
A premium, multi-page commercial refrigeration service company website template built with HTML5, Tailwind CSS 3 (CDN), Vanilla JavaScript, AOS animations, and Lucide Icons.

## Pages
| Page | File | Description |
|------|------|-------------|
| Home 1 | `index.html` | Primary landing page with 6 sections |
| Home 2 | `home-2.html` | Alternate landing with different layouts |
| About | `about.html` | Company story, team, standards |
| Services | `services.html` | Installation, repair, maintenance |
| Pricing | `pricing.html` | Maintenance plans and service rates |
| Industries | `industries.html` | Service areas and industries served |
| Contact | `contact.html` | Validated service request form |
| Login | `login.html` | Client portal login |
| Signup | `signup.html` | Client registration |
| Dashboard | `dashboard.html` | Full client dashboard |
| 404 | `404.html` | Error page |

## Features
- ✅ Light / Dark mode with localStorage persistence
- ✅ RTL layout toggle with localStorage persistence
- ✅ Fully responsive (320px to 1920px+)
- ✅ AOS scroll animations
- ✅ Client-side form validation
- ✅ Dashboard with sidebar navigation and page switching
- ✅ Ticket, invoice, and schedule management UI
- ✅ Temperature compliance charts
- ✅ Lucide icon library
- ✅ Google Fonts (Inter + Outfit)
- ✅ SEO metadata, sitemap.xml, robots.txt

## Tech Stack
- HTML5
- Tailwind CSS 3 (CDN)
- Vanilla JavaScript (ES6+)
- AOS Animation Library
- Lucide Icons
- Google Fonts

## Getting Started
Simply open `index.html` in any modern browser. No build step required.
